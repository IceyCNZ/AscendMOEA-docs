张量算子手册#

导入原则#

公共算子统一从 ascendmoea.operators 导入：

from ascendmoea.operators import nd_sort, operator_ga, tournament_selection

不要从内部 utils 或算法文件导入。内部模块可以调整，公开命名空间是发布接口。

支配关系与排序#

domination_matrix(pop_obj)#

输入 [N, M] 最小化目标，返回 [N, N] 布尔矩阵；第 i, j 项表示第 i 个解支配 第 j 个解。空间复杂度为 O(N^2)，压力测试必须记录峰值内存。

domination_count(pop_obj)#

返回每个个体被支配的次数。适用于强度适应度和快速筛选。

nd_sort(pop_obj, pop_con=None, n_sort=inf)#

返回 (front_no, max_front)。约束输入遵循 g(x) <= 0，不可行解按总违反量处理。 n_sort 可限制需要完成排序的个体数，环境选择只需前 N 个时应传入 N。

父代选择#

tournament_selection(k, n, *fitness)#

进行 k 元锦标赛并返回 n 个索引。多个适应度张量按传入顺序作为字典序优先级，值 越小越优。NSGA-II 常用：

parents = tournament_selection(2, problem.N, front_no, -crowding)

roulette_selection(n, fitness)#

把输入视为越小越优的适应度，经过非负平移后按倒数概率抽取 n 个索引。输入必须非空 且全部有限；它不是直接接收“越大权重越大”的概率权重接口。

多样性与距离#

crowding_distance(pop_obj, front_no)#

按每个前沿分别计算拥挤距离，返回 [N]。边界点为无穷大。实现使用张量排序和散射， 保持稳定排序语义。

pairwise_dist(a, b)#

计算 [A, D] 与 [B, D] 的欧氏距离矩阵 [A, B]。当 A * B 很大时，结果张量本身 就是主要内存项；超出设备容量时调用方会收到明确的内存不足错误。

sequential_distance_truncation(distance, delete_count)#

执行 SPEA2 类逐点距离截断，返回保留掩码或索引。可用以下接口检查可选加速路径：

from ascendmoea.operators import (
    reset_sequential_truncation_diagnostics,
    sequential_truncation_diagnostics,
    warmup_sequential_truncation_accelerator,
)

reset_sequential_truncation_diagnostics()
warmup_sequential_truncation_accelerator()
print(sequential_truncation_diagnostics())

诊断信息用于确认执行路径，不应作为算法适应度的一部分。

变异与交叉#

operator_ga(problem, parent_dec, pro_c=1, dis_c=20, pro_m=1, dis_m=20, half=False)#

根据 problem.encoding 对实数、整数、标签、二进制和排列变量应用对应遗传算子。输入是 父代决策张量，不是 Population。half=True 只返回每对父代的一名后代。

genetic_operator 是同一入口的语义别名。

operator_ga_encoded(...)#

为需要显式编码信息的算法提供编码感知入口。调用前查看函数签名并保证边界、编码和设备 一致。

operator_de(problem, p1, p2, p3, cr=1, f=0.5, pro_m=1, dis_m=20)#

执行批量差分进化与多项式变异。p1、p2、p3 的批量行数必须兼容。 differential_evolution_operator 是同一入口的语义别名。

采样与种群组合#

uniform_point(n, m, device=None)#

生成近似不少于所需结构的均匀参考向量，返回 (points, actual_n)。算法应使用返回的 actual_n，不能假设它始终等于请求的 n。

merge_pop(*populations)#

沿个体维合并多个 Population。各字段列数、设备和 dtype 必须一致。

non_dominated_mask(obj)#

返回目标矩阵的非支配布尔掩码，不处理约束。约束任务应先筛选可行解，或使用 nd_sort(obj, con)。

设备与精度规则#

  • 所有输入张量必须位于同一设备。

  • 不要在算子内部创建未指定设备的 torch.zeros 或 torch.arange。

  • 用稳定排序保留确定性平局语义。

  • NPU 上正式计时前应完成一次同形状预热并同步。

  • 比较 CPU/NPU 结果时使用绝对误差与相对误差双重容差，并单独核对排序、掩码和索引。

  • 对 N x N 算子同时记录墙钟时间、峰值主机内存和峰值设备内存。

独立算子示例#

from ascendmoea.operators import crowding_distance, nd_sort, operator_ga
from ascendmoea.problems import DTLZ2

problem = DTLZ2(n=100, m=3, max_fe=10_000)
population = problem.initialization()
front_no, _ = nd_sort(population.objs, population.cons, problem.N)
crowding = crowding_distance(population.objs, front_no)
offspring_dec = operator_ga(problem, population.decs)
offspring = problem.evaluate(offspring_dec)
