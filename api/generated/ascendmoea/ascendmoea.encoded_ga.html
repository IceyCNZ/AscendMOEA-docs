operator_ga_encoded

Apply the genetic operator independently to each encoding group.

API#

ascendmoea.encoded_ga.operator_ga_encoded(problem, parent_dec: torch.Tensor, pro_c: float = 1.0, dis_c: float = 20.0, pro_m: float = 1.0, dis_m: float = 20.0, half: bool = False) → torch.Tensor#

Apply the genetic operator independently to each encoding group.

Args: problem: Problem providing bounds and per-variable encoding codes. parent_dec: Parent decision tensor arranged in two equal halves. pro_c: Crossover probability. dis_c: Real-valued crossover distribution index. pro_m: Mutation-rate multiplier. dis_m: Real-valued mutation distribution index. half: Return one child per parent pair when true.

Returns: Encoding-valid offspring decisions.
