class ascendmoea.workflow.RunConfig#

Define reproducible execution settings for one optimization run.

Args: device: Device string or PyTorch device. None uses environment-based automatic selection. seed: Optional random seed shared by all supported random generators. cpu_threads: Intra-op CPU thread count for this process. synchronize_timing: Synchronize accelerator queues around wall timing.
