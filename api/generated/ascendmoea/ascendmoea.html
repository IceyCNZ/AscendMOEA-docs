class ascendmoea.Algorithm(save: int = -10)#

Bases: abc.ABC

Base class for evolutionary algorithms.

Custom algorithms implement :meth:_solve and retain the evolutionary loop inside that method. Calling :meth:not_terminated records history, dispatches callbacks, and enforces the function-evaluation budget.

Initialization

Initialize history storage.

The absolute value of save selects the maximum number of evenly distributed history slots. Zero and one both retain the latest slot.

'Algorithm'

class ascendmoea.Problem(n: int = 100, m: int | None = 2, d: int | None = 10, max_fe: int = 10000)#

Bases: abc.ABC

Base class for vectorized optimization problems.

Subclasses normally implement :meth:setting and :meth:cal_obj; they may also implement :meth:cal_con, :meth:get_optimum, and :meth:get_pf. Objective and constraint functions must accept an (N, D) tensor and evaluate the complete batch without per-individual Python loops.

Initialization

Initialize dimensions, evaluation budget, and CPU-resident state.

Args: n: Requested population size. m: Number of objectives. None lets :meth:setting choose it. d: Number of decision variables. None lets :meth:setting choose it. max_fe: Maximum number of objective-function evaluations.

Apply optional problem-specific repair to a decision batch.

The generic evaluator has already enforced bounds and discrete-variable rounding before this hook is called. Subclasses may override the method for additional vectorized repair while preserving the (N, D) shape.
