LMEA

Optimize large-scale problems through variable clustering and grouping.

API#

class ascendmoea.algorithms.lmea.LMEA(save: int = -10, n_sel: int = 5, n_per: int = 50, n_cor: int = 5, operator_type: int = 1)#

Bases: ascendmoea.core.Algorithm

Optimize large-scale problems through variable clustering and grouping.

Initialization

Configure variable-analysis sampling and variation.

Args: save: History retention policy inherited from :class:Algorithm. n_sel: Population samples used to analyze each variable. n_per: Perturbations generated per selected solution. n_cor: Trials used in each pairwise correlation test. operator_type: 1 selects GA and 2 selects DE.
