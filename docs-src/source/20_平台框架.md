# AscendMOEA 平台框架

AscendMOEA 将运行环境与硬件控制、张量化算子、算法组合以及问题扩展统一在一条可复现的执行链路中。

```{image} _static/AscendMOEA_framework.svg
:alt: AscendMOEA 平台框架
:class: framework-figure
:width: 100%
```

平台以统一的 PyTorch 张量状态连接 CPU 与华为昇腾 NPU 后端，并在同一工作流中组织初始化、进化、选择、终止、指标计算和实验记录。算法、问题、算子、指标与注册表均通过开放接口扩展。
